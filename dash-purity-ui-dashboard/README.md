# Purity UI Dashboard - Dash Version

A Dash rebuild of the Purity UI Dashboard (Chakra UI) design, with a multi-page layout matching the provided screenshots.

## Pages
- Dashboard
- Tables
- Billing
- Profile
- RTL (placeholder)
- Sign In
- Sign Up

## Run
```bash
pip install -r requirements.txt
python app.py
```

Then open http://localhost:8053
